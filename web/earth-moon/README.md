# 日地月实验室 · 同一轮月亮，两种视角

第03、04讲的第一阶段教学网页。空间沙盘、地心月面、地面太阳圆面和物理影锥联动；每组实验有解释、公式、操作提示和课程图版，另含两讲完整文章。

## 打开

[本机预览](http://127.0.0.1:4174/)仅在服务运行时可用。服务关闭后双击本目录 `打开日地月.cmd`，或在工作区执行：

```powershell
node web/earth-moon/server.mjs
```

需要支持WebGL 2的浏览器。通过HTTP打开，不直接双击HTML；引擎、纹理、全文、公式和六幅图版均在本地，核心实验可断网运行。外部来源链接需网络。本机服务仅监听127.0.0.1，未发布到互联网。

## 四组实验

1. **月相从何而来**：拖动月球或播放，空间位置、观察月面、受光比例与相位角一起变化；四种月相可直接定位。
2. **同一面，也在转**：金点固定在月面，比较同步自转与完全不自转；偏心轨道开关演示经度天平动。
3. **两种月，两种终点**：从起点走到恒星月、朔望月，联动日心地球小图、相对进度与月面，解释27.32天与29.53天。
4. **走进影子**：比较日全食、环食、偏食、新月无食和月全食；改变倾角、交点线、距离和地面点，联动物理影锥与圆面。局部时间滑块覆盖理想新/满月前后6小时，播放速度支持1.44或14.4分钟/秒。

拖动空白旋转空间视角，滚轮缩放；月球附近拖动改变轨道位置。俯视、斜看、真实比例、重置可直接操作。手机采用上下排列，向下滚动查看观察窗口与控制。空格在非表单/弹窗焦点时播放或暂停，Escape关闭阅读弹窗。

“真实比例”只将地球、月球和地月距离恢复为统一比例，太阳仍为方向标志；月面观察窗口放大月面，太阳窗口用共同角尺度。图版和文章在弹窗中阅读，引用保留原编号并链接到原来源。“继续读”直接定位该实验对应的正文节；打开阅读暂停轨道。

## 模型范围

这是理想轨道教学实验，日数没有真实日期含义。展示与物理坐标分开；日食类型和阴影不从沙盘缩放读取。距离是独立比较参数，未联动周期。交点固定；偏心开关只演示经度天平动。地面点相对月下点移动，不是固定城市的食过程预报。红光选项和暗部底光是示意，非辐射/大气模型。

完整计算、来源、许可和待办见 [SOURCES.md](SOURCES.md)。原文、Pro范例及旧太阳系网页未改。金星相位、逆行与凌星等扩展暂未实施。

## 文件与维护

`physics.mjs`是独立千米几何；`app.js`绘制双视角、着色器、影锥与交互；`content.js`为实验解释。`data/resources.json`记录本地复制及源/输出哈希，`reading/03.html`、`04.html`保留完整原文。

```powershell
# 定向复制已有本地资源/阅读副本，保护被修改的输出，不写原文章。
conda run -n dl_env python web/earth-moon/tools/prepare-local.py
# 先启动本机服务，再运行数学与实际浏览器检查。
node web/earth-moon/tools/check.mjs
```

检查工具使用本机已有Playwright和Edge，路径写在工具中，换机器时须定位相应运行时；网页本身不依赖测试运行时。不需要安装新包。
