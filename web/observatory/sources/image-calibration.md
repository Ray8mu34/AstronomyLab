# 图像校准与孔径测光

## 数据与单位

本工具的 64 × 64 像素数组由解析模型生成。两颗恒星的高斯点扩散函数逐像素积分，视场、相对响应、偏置条纹和热像素位置保持固定。当前工具不读取原有 M17 数据。

| 参数 | 数值 |
| --- | --- |
| 增益 g | 2 e⁻/ADU |
| 单次读出噪声 | 5 e⁻ RMS/px |
| 偏置 | 600 + 14 sin(0.48y) + 0.18(x−31.5) ADU |
| 恒星 A | (22.5, 36.5) px；σ = 1.8 px；总计数率 700 e⁻/s |
| 恒星 B | (46.5, 20.5) px；σ = 2.2 px；总计数率 420 e⁻/s |
| 主暗场的单张曝光 | 120 s |
| 平场每张平均光电子数 | 20000 e⁻/px |
| 默认科学曝光 | 60 s |
| 默认天空 | 8 e⁻/s/px |
| 默认暗电流 | 0.5 e⁻/s/px；两个热像素为该值的 71 倍 |
| 默认主校准帧数量 | 每种 16 张 |
| 默认随机样本编号 | 4729 |

坐标 x、y 表示像素中心，均由 0 到 63。光学渐晕与一处局部响应下降组成相对平场，除以其全图均值后得到 Fᵢ；因而平均 Fᵢ = 1。给定的恒星计数率和天空率对应这一平均响应基准。

## 原始帧与校准帧

设 Sᵢ 为天体计数率，b 为均匀天空率，dᵢ 为暗电流率，t 为曝光时长。原始读数为

Rᵢ = Bᵢ + [Poisson(t(Fᵢ(Sᵢ+b)+dᵢ)) + Normal(0,r²)]/g。

偏置与暗信号为加性项，相对响应为光电子项的乘性因子。三项校准应用到同一原始数组：

Cᵢ = (Rᵢ − B̂ᵢ − t d̂ᵢ/g)/F̂ᵢ。

三个复选框分别控制这些算子。当前处理结果可以保留某个加性项，或保持未经响应校正的计数，用来观察各校准量的作用。孔径测光模式始终使用三项完成的全校准数组，天空在测光步骤中单独估计与扣除。

主偏置使用 N 张独立读出的均值，因此单像素误差为 r/(g√N)。主暗率由 N 张 120 s 曝光的总暗电子数与读出噪声求均值；主平场由 N 张均匀照明的光电子计数与读出噪声求均值，再除以其全图均值。主暗与主平场在这里已经完成上游加性校准，并将其上游偏置/暗场扣除视为精确；三个主校准量的估计噪声独立。平场的均值归一化会引入像素间的共同缩放。

原始帧和三种主校准量使用分别播种的随机流。改变显示白点、所选像素、孔径或目标恒星时，原始曝光保持逐像素相同；改变主校准帧张数也保持原始帧相同。点击“换一次曝光”改变样本编号，重新生成曝光和主校准量。关闭噪声得到各量的期望值。负的校准残差继续保留在数组和测光中；灰度显示在下限处截断。

主图使用共同 ADU 范围与 asinh 映射，白点只改变显示。偏置、暗场和无量纲平场各自的显示上下限在小图旁标出。模型包含理想线性探测器、恒定温度与独立计数/读出；饱和、宇宙线、追踪漂移和重采样相关性不在本模型中。

## 孔径与天空环

孔径中心取所选合成星的已知中心，半径为 1–8 px。天空环的内、外半径固定为 10、14 px。对圆边缘像素使用 8 × 8 子像素的面积分数；完全在圆内的像素权重为 1。显示的图像每个样本仍是完整像素积分值。

A = Σwᵢ，C̄天空 = ΣuᵢCᵢ / Σuᵢ，N净 = g(ΣwᵢCᵢ − A C̄天空)。

其中 w 是孔径权重、u 是天空环权重。净计数率为 N净/t。曲线使用相同天空环、同一幅校准图，分别计算不同孔径半径的结果。虚线给出生成模型的恒星总计数率；小孔径截取部分点扩散函数，足够大时曲线靠近总值。天空估计的随机误差、残余校准噪声与孔径截取都会影响当前测量；本工具显示计数，不给出未经完整协方差传播的精度条。

## 来源

以下于 2026-10-30 查阅，采用独立表述与原创图形。

- [STScI：STIS 校准步骤](https://hst-docs.stsci.edu/stisdhb/chapter-3-stis-calibration/3-4-descriptions-of-calibration-steps)：偏置、暗信号和相对响应的校准职责；具体仪器流水线应按其数据类型安排。
- [Astropy CCD Guide：平场的加性校准](https://www.astropy.org/ccd-reduction-and-photometry-guide/v/dev/notebooks/05-03-Calibrating-the-flats.html)、[合并与归一化](https://www.astropy.org/ccd-reduction-and-photometry-guide/v/dev/notebooks/05-04-Combining-flats.html)：缩放暗场时须区分偏置与暗电流，归一化平场用于相对响应校正。
- [Photutils：Aperture Photometry](https://photutils.readthedocs.io/en/latest/user_guide/aperture.html)：孔径面积权重、局地天空估计与背景扣除。这里自行实现子像素面积求积，未载入 Photutils 运行库。
- [Hörmann (1993)：The transformed rejection method for generating Poisson random variables](https://doi.org/10.1016/0167-6687(93)90997-4)：高均值 Poisson 变换拒绝抽样；实现参数与 [NumPy 作者实现](https://github.com/numpy/numpy/blob/main/numpy/random/src/distributions/distributions.c)交叉检查。低均值采用乘积法；高斯读出噪声由 Box–Muller 变换生成。运行时为本项目 JavaScript，不依赖 NumPy。

上述资料和论文提供方法依据；本工具未复制观测图像、仪器数据表或外部运行资产。全站已有第三方许可待核状态保持不变。
