# 太阳系 · 一张正在运动的地图

第01、02讲的独立 Three.js 教学网页，包含太阳系沙盘、按问题组织的行星介绍和完整文章。课程 `lesson.md` 仍为正文源；此次创建没有修改16篇文章或用户Pro范例。

## 打开

当前本机预览：[http://127.0.0.1:4173/](http://127.0.0.1:4173/)。服务关闭后，双击本目录 `打开太阳系.cmd`，使用现有Node.js启动本地服务并打开浏览器。也可在工作区运行：

```powershell
node web/solar-system/server.mjs
```

浏览器需要支持WebGL 2。通过HTTP地址打开；直接双击 `index.html` 会受到本地文件模块限制。引擎、贴图、数据、全文和图片都在本地，核心展示可断网使用，外部阅读链接需要网络。服务只监听本机，未发布到互联网。

## 使用

- 拖动旋转、滚轮缩放；点击球体、标签或下方行星按钮靠近观察。选中时暂停公转；恢复播放后镜头跟随它。
- 太阳和八颗行星各有“概览”“深入一层”“参数与尺度”，从金星温室效应、水星3∶2共振、木星密度等问题进入解释。
- 主小行星带、柯伊伯带的介绍连接共振、分类和太阳系边界。
- “宇宙沙盘”压缩距离、放大天体；“轨道距离”对位置使用同一线性比例、天体仍放大；“尺寸比较”按平均半径同比例比较八颗行星。
- 左下信息按钮解释模型，右上“资料与图注”显示出处。“阅读全文”展开对应第01或02讲，含本地图片和原来源编号链接。
- 日期2000—2049年；空间键切换公转播放，Escape退出阅读或返回整体。网页适配桌面和手机。

## 文件与核查

`content.js`为介绍，`app.js`为3D交互，`physics.mjs`计算JPL近似位置。`textures/`有13份贴图（其中金星地表、月球为备用），`media/`有6幅课程图版，`reading/`为完整文章副本。

[SOURCES.md](SOURCES.md)记录出处和限定；`data/resources.json`记录下载URL、尺寸、SHA256；`data/reading-manifest.json`记录原文章与复制素材哈希；`references.html`提供文章科学来源导航。
