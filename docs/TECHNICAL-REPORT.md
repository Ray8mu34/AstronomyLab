# 技术与性能报告

核查日期：2026-10-04。对象为 AstronomyLab 独立发行副本，公开站点 https://lab.zjuaaa.cn/。内容包含 11 个交互实验室、16 篇文章、素材与来源导航。

## 技术栈与执行位置

| 部分 | 实现 | 主要资源消耗位置 |
| --- | --- | --- |
| 页面与交互 | 原生 HTML、CSS、JavaScript ES Modules | 浏览器 |
| 三维可视化 | Three.js r180、OrbitControls、WebGL2 | 浏览器 CPU/GPU |
| 图像与图表 | Canvas 2D、客户端数学模块、Float32 数据 | 浏览器 CPU/内存 |
| 文章 | 已生成 HTML，保留 Markdown 编辑源 | 浏览器阅读；服务器发送文件 |
| HTTP 服务 | Node.js 22 标准库，无 npm 运行时依赖 | 服务器轻量路由、文件传输、少量 HTML 适配 |
| 对外访问 | Nginx 反向代理、TLS、gzip | 服务器网络、TLS/压缩 CPU |
| 进程维护 | PM2、既有系统启动服务 | 服务器 |

网站没有数据库、登录系统或服务端三维渲染。服务器不需要显卡；浏览器控制参数和渲染画面时，不会把每一帧交给服务器计算。文章导出和数据预处理工具属于维护流程，不参与日常访问。

## 这台服务器是否足够

在用户提供的 2 核 CPU、2 GB 内存服务器上，与现有官网共用 Nginx。部署后实验室 Node 进程的 PM2 内存读数约 63 MB，检查时空闲 CPU 读数为 0%；系统可用内存约 1.04 GB，应用目录含 Git 历史约 186 MB。以上为部署时快照，包含读取口径和时点影响，并非峰值、压力测试或并发容量保证。

针对一位讲授者打开网站的用途，当前服务器资源有余量，可以使用。三维实验是否流畅主要取决于讲授电脑的 WebGL2 支持、显卡、浏览器和窗口分辨率。公网日地月实验已实际加载并渲染，调整时间后几何受光比例由 14.7% 更新至 100.0%；图像实验切换赋色成功。验证使用软件 WebGL，不提供实际课堂电脑 FPS 结论。

源码与运行素材合计约 101 MiB，不会在打开首页时全部下载。原有素材中单张图片最高约 9 MiB；3 Mbps 带宽可能让首次打开大图较慢。已开启 gzip 处理文本和可压缩数据，JPEG/PNG 原图仍保留。一个讲授者使用时，优先提前打开所需实验和文章；如以后出现实际加载瓶颈，再考虑适合课堂屏幕的图片尺寸、缓存校验或 CDN。无需为浏览器渲染升级服务器 GPU。

## 部署隔离与验证范围

源码仓库、服务目录、PM2 名称、Nginx 配置、子域名和证书均独立。服务仅监听 `127.0.0.1:4180`，由 Nginx 提供公网 HTTPS。原课程 3299 个受保护文件与官网本地 748 个受保护文件的 SHA256 未改变；原卷、教师记录、私钥、私有 QA 与原始科学数据压缩包未上传。

本地独立副本：31 个页面浏览器检查、37 个 HTTP 检查，覆盖 11 个实验室、16 篇文章及嵌入图像。生产 Node：发行文件逐项 SHA256 核验、31 个页面和 145 个 HTTP 检查，包括资源 MIME 与受限路径返回 404。公网 HTTPS：4 个代表页面、两项参数交互，未发现脚本异常或失败请求；证书校验、HTTP 跳转、gzip 和续期模拟通过。

这些结果证明当前发行可部署与访问，不替代真人科学审校、真实授课试用或教材对照。第三方素材与数据的许可待核事项见 `THIRD_PARTY.md`，没有因上传 GitHub 而自动解决。后续维护、原官网部署文件位置和回滚边界见 `DEPLOYMENT.md`。
