# earth.nullschool：数据、显示与流动各有身份

2026-10-06｜[实际产品](https://earth.nullschool.net/)。当前新版作为研究对象，没有用 classic 界面替代。

实际操作：菜单开关、Wind → Temperature 叠加、停止粒子动画、数据时刻 +8 hours、点选地图位置、窄屏菜单收起、查看 Settings。HTML 与内嵌 CSS 成功取得；设置含地图、信息栏、插值、字号与粗体，本次未看到明暗主题入口。当前背景是暗色；CSS 里含 dark 字样不构成双主题证明。

## Visual Theme & Atmosphere

主体是一张可旋转的地球数据图，不是仪表盘。默认只有 earth 菜单与推广入口；展开后才出现条件、来源、色标和工具。极简首屏有沉浸感，也让数据身份默认不够显眼，Lab 不应全盘复制隐藏策略。

关键特征：数据画面优先、可收起菜单、条件成行、依模式变化的参数组、独立叠加与动画、点选局部读数、单位切换入口。

## Color Palette & Roles

| Hex / 角色 | 来源 | 作用 |
| --- | --- | --- |
| `#000005` 页面底 | 实测 body `rgb(0,0,5)`，内嵌 CSS | 让地球与流场成为主体 |
| 深色透明菜单、浅文字 | 实测入口背景 `rgba(0,0,5,0.85)` 与截图 | 维持数据图连续性 |
| 色标 | 叠加切换前后截图 | 编码当前物理量，不是品牌装饰色 |
| 点选圆圈 | 点选后的截图 | 连接地图位置与局部读数 |

变化叠加量会改变色标，所以色标必须和数据名一起解读；相似颜色不代表相同单位或量。

## Typography Rules

实测字体栈为 `MPLUS1-base, NotoSans-base, system-ui, sans-serif`；HTML 内 @font-face 提供 400/600 权重。设置允许改变字号与粗体，见[设置截图](images/earth-settings.jpg)。

| 角色 | 已确认的层级 |
| --- | --- |
| Display / H1 | earth 同时是菜单入口，实测 18px |
| H2 / H3 | 未见传统网页式标题序列；菜单由语义行组织 |
| Body | 数据名、来源、时刻与控件成行，部分控件实测 16px |
| Small / Mono | 未确认完整尺度或等宽用法，不猜造 |

简短缩写提高密度，但对新手有学习成本；Lab 应优先中文任务语言和明确单位。

## Component Stylings

菜单区分 Date、Data、Source、Scale、Control、Mode、Animate、Height、Overlay、Projection。Mode 是 tab，高度/叠加/投影是 radio；选择状态可以从 DOM 读取。设置对话框进一步承接非主要选项。

点选地图后，检查圆圈留在地图，旁边出现坐标、风向风速与温度；单位是可点击控件。Now 和日期步进属于数据时刻，Start/Stop Animation 属于粒子流动。没有观察到通用“全部重置”按钮，不能将 Now 解释为清除所有设置。部分局部读数按钮实测高 24px，不是适合 Lab 直接采纳的触控目标。

## Layout Principles

桌面画布全屏，但默认地球圆盘直径约为视口高度的七成；地球外接框约占三分之一屏幕面积，实际圆盘约四分之一。空白让主体显著，不能用“全屏 canvas”宣称科学图形占满画面。

展开菜单约占左下五分之一左右的视口面积，覆盖地球一部分；点选读数附在菜单上方。控制以文字成行，不用一组大型装饰卡片重排数据。完整 spacing/radius 尺度未提取，只记录位置关系。

## Depth & Elevation

地图、粒子、检查标记、读数与菜单各自承担不同内容。透明菜单可以看见背景，依然会遮挡数据；在窄屏中尤其明显。设置对话框覆盖并压暗画面，适合暂时调整全局显示，但不应成为主实验控制常驻层。

## Interaction & Motion

Wind → Temperature 后，Data 行新增 Temperature @ Surface，色标与地图颜色变，风场粒子继续运动。停止动画后，数据时刻仍为 00:00，温度叠加保留，粒子逐渐消退；它不是冻结真实天气随时间演化。

随后 +8 hours 将数据时刻变为 08:00，地图刷新，见[时刻改变证据](images/earth-data-time-change.jpg)。点击一个地图位置，圆圈、坐标与带单位的读数出现。动画运动和数据时刻是分开的 UI 维度；不应把每条粒子线称为真实空气团的历史轨迹。本轮没有录屏或流场数值验证，hover、focus、精确 easing 未系统提取。

## Responsive Behavior

390×844 中地球保持大尺寸并横向裁切，菜单接近全宽，使用内部滚动和多行折行；选点读数随菜单布局移动。收起菜单后仍有检查圆圈和读数，见[窄屏收起](images/earth-mobile-scene.jpg)。裁切适合地图探索，但不适合需要同时看到完整空间关系的实验。

内嵌 CSS 使用 4/3 的 min/max-aspect-ratio 条件，不是只按手机宽度处理。本次没有验证手指拖动、内部滚动触感或全部参数组；小触控项与缩写密度是应避开的复制点。

## Agent Prompt Guide

- 提示一：图像/曲线的最小状态栏保留数据身份、当前显示变换与单位，完整来源再按需展开。
- 提示二：把源数据操作、显示处理和动画操作分组，修改一组时明确哪些画面与读数回应。
- 提示三：点选位置与局部读数保持一致，收起控制后仍能追踪当前检查点；窄屏避免菜单压住目标。

迭代检查数据时刻、色标单位、动画含义、检查点身份和面板遮挡。适合 Lab 的是数据语境与局部检查，不是密集缩写、默认隐藏全部身份、实时气象服务或其地球皮肤。
