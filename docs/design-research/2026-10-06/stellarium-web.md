2026-10-06｜[实际产品](https://stellarium-web.org/)。本次保留默认地点 Unknown，未请求设备定位；页面显示的日期/时间不等于本机时区或用户位置。

实看：默认侧栏、收起侧栏、选中 Vega、展开时间、暂停、390×844 面板与收起状态、Night Mode。日期增量点击没有生效；一次预期拖动时间条实际变成星空平移，不能算成功调时。HTML、关联 CSS、Roboto 字体定义成功取得；大型样式只取前约 200 KB。夜间红色模式已核实，未确认独立浅色 UI 主题。

## Visual Theme & Atmosphere

星空与地平景观承载“我在看哪里”的语境，界面贴边。默认侧栏包含设置、行星与推广内容，可收起；后者不是 Lab 需要复制的导航负担。

关键特征：大范围天空、地平方位、可折叠侧栏、底部图层栏、对象选择标记、局部对象卡、地点/时间入口、夜间视觉模式。

## Color Palette & Roles

| Hex / 角色 | 来源 | 作用 |
| --- | --- | --- |
| `#424242` 控件底色 | 实测部分按钮 `rgb(66,66,66)` | 把操作区从天空分出 |
| 暗色半透明对象卡、浅字 | 实际截图 | 不切离天空即可查对象 |
| 红色夜间表示 | [Night Mode 截图](images/stellarium-night-mode.jpg) | 具有特定观察用途，不是普通深浅主题 |

只记录已确认的中性色，未提取完整调色板。夜间模式会影响科学画面和文字的颜色，不宜用于必须判读图像赋色的工具。

## Typography Rules

body 实测 `Roboto, sans-serif`；页面关联 [Roboto 定义](https://fonts.googleapis.com/css2?family=Roboto:wght@100;300;400;500;700;900&display=swap)。

| 角色 | 观察/实测 |
| --- | --- |
| Display / H1 | 紧凑顶部品牌；星空标签不属于 DOM 标题尺度 |
| H2 / H3 | 对象名突出、属性在下；未抽取统一标题数值 |
| Body | 对象资料短文与属性表分开 |
| Small | 部分按钮实测 14px，另有 16px |
| Mono | 未确认对象与时间读数的等宽字体，不外推 CSS 通用规则 |

小型读数表节省空间，却不适合不加调整地作为现场投影字号。

## Component Stylings

顶部搜索、FOV 与 Observe 提供查找/观察入口；底部图标切换星座、气氛、地景和网格等图层。地点和日期各自打开局部面板。选择 Vega 后，场内选择标记与左上信息卡对应，卡片包含身份、属性、观测坐标与资料入口，并有关闭按钮。

时间弹层把日期、时分秒、暂停和昼夜条集中显示；这组控件用于观察时刻，而不是实验 t=0。部分窄屏按钮实测为 36×36、40×42，顶部菜单为 48×48；不是所有可点击图标的完整触控尺寸审核。

## Layout Principles

默认侧栏约占五分之一宽度；收起后星空几乎覆盖全屏，顶部带和底部栏约各占少量高度。对象卡只覆盖左上局部，Vega 的场内标记仍可见，视口没有改成“资料页＋小配图”。

时间面板出现于右下，桌面可以保留大部分星空；窄屏对象卡与时间同时打开时，主要关系被遮挡。无证据支持完整的间距与圆角尺度，不用 UI 框架默认值代替产品实测。

## Depth & Elevation

天空、地景、对象标签、操作栏、对象卡和时间弹层构成不同语义层。半透明允许看见背景，但不能解决遮挡；窄屏重叠是实例。本次不宣称其阴影系统或无障碍层级已验收。

## Interaction & Motion

选中 Vega 后没有立即把天空切成另一张固定图，标记保留在星空位置，并可关闭资料。时刻自然推进时，坐标读数变化；暂停控件切为播放符号并保留时刻。日期增量与预期时间拖动未成功，因此没有证据支持“本次已验证一小时改变后的因果结果”。

有价值的是可见的观察语境与对象上下文；仅看到天空移动不足以解释机制。Lab 的天球实验应突出纬度、参照与理想化边界，不复制完整星图产品，也不改变 Sky。Night Mode 实际切换后已恢复；hover、focus、转场时长未专项测试。

## Responsive Behavior

390×844 中品牌与 FOV 收敛，搜索和 Observe 保留，地点/时间成为底部小图标；对象卡接近全宽，时间弹层也接近全宽。两个面板同时开会严重挤占主体。收起面板可恢复观察，见[窄屏收起状态](images/stellarium-mobile-scene-paused.jpg)；截图显示暂停 00:36:55，不能作为调时成功证据。

已取 CSS 有 600、960、1280 等媒体条件；其中包含框架规则，不能把每个条件都归因于这几个控件。模拟窄屏不等于移动端首次加载、实体手机或定位服务通过。

## Agent Prompt Guide

- 提示一：让当前对象在场景、标记和上下文资料中一致；关闭资料后保留对象状态。
- 提示二：把时间、观察位置与参照说明作为当前条件展示，不让它们淹没在百科资料里。
- 提示三：窄屏一次只展开一个主面板，核心播放/复位保留文字，保护主体的观察面积。

迭代检查观察语境、卡片遮挡、图标可发现性、退出后的状态和信息密度。适合借用对象选择与观察条件；不借用品牌、地景、星表、完整观测功能或夜间红色皮肤。
