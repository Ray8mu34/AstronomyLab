# 着陆点火与分级预算：计算方法及来源

2026-10-04实际重新查阅。组件为 `modules/landing-staging-lab.js`、`landing-staging-lab.css`，纯数值模型为 `landing-staging-physics.mjs`。仅用于课程第15讲的教学实验；所有质量、推力、比冲与流率都是虚构教学参数，没有真实载具测量或任务结果。

## 主来源与支持范围

- [NASA Glenn：Specific Impulse](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/specific-impulse/)：读取比冲、等效排气速度、推力与质量流率的关系。采用 `ve = Isp·g₀`、`T = q·ve`，其中q为正的推进剂消耗流率；g₀固定为标准重力9.80665 m/s²。比冲的秒不是持续点火时长。
- [NASA Glenn：Ideal Rocket Equation](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/ideal-rocket-equation/)：读取变质量动量推导、质量比对数及恒定重力项。采用本文符号 `Δv = ve ln(m₀/mf)`；NASA原图mf表示full（初始质量），与这里mf表示final不同。NASA此页将g₀笼统写为gravitational constant；本模块按比冲页面所给单位明确解释为标准重力加速度，与万有引力常数G不同。仅使用稳定公式，未继承该页示例中的型号性能、技术现状或成本概括。
- [NASA Glenn：Rocket Thrust](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/rocket-thrust/)：读取火箭携带推进剂与氧化剂、喷流及出口压力项的推力关系。本模块使用恒定等效排气速度，将压力贡献包含在等效性能中，没有另行模拟喷管流场或推力随气压变化。

## 着陆：可变质量，一维向上为正

初始距地面300 m、v = −40 m/s，干质量1800 kg，推进剂200 kg，固定推力36 kN，比冲280 s。局部重力固定为9.80665 m/s²。关机时自由下落；下降到用户选定高度时瞬间建立向上推力。动力学为dh/dt=v、dv/dt=T/m−g、dm/dt=−T/(Isp·g₀)。推进剂包含燃料与氧化剂。

燃烧段使用这些方程的解析积分，并非用匀加速度公式假装燃料减少。设点火后经过τ，点火质量mᵢ、消耗流率q=T/ve、m=mᵢ−qτ：v = vᵢ + ve ln(mᵢ/m) − gτ；h = hᵢ + vᵢτ + ve[τ − (m/q)ln(mᵢ/m)] − gτ²/2。小τ使用级数避免消减误差。干质量不变；燃尽后T=0并转自由运动。

首次接地在下降区间二分求h=0；二分显式处理两个端点的根，拒绝不包围根的区间。当h的最小值恰为0时没有正负号交叉，另行定位v=0并检查h，避免漏掉相切触地。浮点误差容差随积分式中各项的量级计算，仅在机器舍入范围内合并燃尽、零速与触地的同刻事件。地面接触优先于同刻点火：选择0 m点火时，自由下落在4.742705941 s首次接地，触地前v=-86.510057219 m/s，推进剂200 kg全部保留，没有随后在地下燃烧。报告触地前速度与剩余推进剂，随后关机。触地速率不超过2 m/s只记为本模型低速触地，不表示实际结构、横向速度或姿态验证成功。

点火过早时先定位下降速度为零的高度，再观察最多2.5秒，若较早燃尽就结束该次观察，明确标为未触地；显示实际观察时长，并登记燃尽事件。零速与燃尽恰好同刻且仍高于地面时，观察时长为0，不声称已经观察到上升。比如280 m点火、55 kN推力、50 kg推进剂，零速后实际观察0.295634246 s即燃尽。未模拟悬停制导、节流或真实发动机再启动。场景按该次预测的高度范围线性缩放，箭体与速度箭头尺寸放大，核心数值与曲线按物理单位显示。

默认临界点火高度约204.7320716 m、总经过时间8.7673262 s，触地时剩余推进剂110.3145736 kg。280 m点火在离地约161.4774832 m停止下降；130 m点火触地前v约−52.6576430 m/s。临界参数由模型求根，不是预先写死的成功动画，也不是实际制导软件。

## 分级：相同资源的理想对照

两条初始火箭完全相同：一级干质量10 t、推进剂80 t，二级干质量3 t、推进剂25 t，有效载荷2 t；初始总质量120 t。两级相同比冲300 s、ve=2.941995 km/s；流率分别0.5和0.15 t/s，一级燃烧160 s，二级166.6667 s。

一级烧完，两条均获得约3.2321119 km/s的理想Δv。一条抛下空一级10 t，另一条保留。分离瞬间速度连续，二级质量分别从30和40 t开始；结束分别5和15 t。二级Δv约5.2713474与2.8855948 km/s；总理想Δv约8.5034593与6.1177066 km/s。两条消耗的推进剂均105 t，相同载荷、流率、比冲及初始质量。

分离没有弹射推力；空一级以分离时速度继续匀速运动，上级随后加速，所以相对间距从零连续增大。场景只显示压缩后的相对结构和间距，没有用地面发射轨迹解释无重力预算。携带空一级是质量账本的理想对照，未模拟发动机排气的真实结构布局。曲线中的质量只统计仍连在主火箭上的质量；已抛出的结构和已喷出的推进剂在守恒测试中另外计入。全部忽略引力与阻力；总Δv不是真实入轨速度，也不表示已完成任务。
