# 地月潮汐：模型与来源

两个模式采用近圆、共面、轨道平均的潮汐耦合模型。月球锁定模式包含月球自转与地月相对轨道，地月演化模式包含地球自转与同一相对轨道。各模式固定参与耗散天体的转动惯量；另一颗天体的自转不参与这组计算。潮汐形变的相位偏移产生一对相反力矩，自转与轨道交换角动量，同时损失机械能。

## 归一化与方程

设总质量为 M，约化质量 μ = M地 M月 / M，初始距离为 a₀，n₀² = GM / a₀³。定义 x = a/a₀、u = Ω/n₀、λ = I/(μa₀²)、τ = n₀t。角动量单位为 μa₀²n₀，机械能单位为 μa₀²n₀²。圆轨道满足

```
n/n₀ = x^(-3/2)
L轨道 = sqrt(x)
L自转 = λu
E轨道 = -1/(2x)
E自转 = λu²/2
```

采用小相位滞后形式的线性耗散律，力矩随 Ω−n 变号，幅度包含 a⁻⁶ 因子。界面中的 κ 是选定的演示耗散强度：

```
du/dτ = -κ [u - x^(-3/2)] x^(-6)
τ轨道 = κλ [u - x^(-3/2)] x^(-6)
τ自转 = -τ轨道
sqrt(x) = 1 + λ(u₀-u)
```

最后一式直接执行总角动量守恒。积分只推进 u 和两个转角，每一步从守恒式得到轨道半径。自转快于公转时，轨道角动量增加，半径增大；自转慢于公转时，轨道角动量减小，半径减小。圆轨道能量对角动量的导数等于公转角速度，因而

```
dE机械/dτ = -κλ [u - x^(-3/2)]² x^(-6)
Q(τ) = E机械(0) - E机械(τ)
```

两种交换方向均耗散机械能。同步初值 u₀ = 1 给出恒定圆轨道、零力矩与零耗散。图中能量变化统一除以 I n₀²，角动量曲线统一除以本次初始总角动量。

κ 的默认值为 0.04，可在 0.01—0.08 之间改变；它设定这组教学模型的演化速度。时间轴使用无量纲 τ，固定耗散模型用于比较守恒关系、力矩方向与同步极限。真实地月年代需要另行拟合海盆、地球内部、轨道偏心率、太阳力矩及其长期变化。

数值积分采用固定步长 Δτ ≤ 0.25 的四阶 Runge–Kutta；滑块或恢复得到非整步时间时，再推进相应余步。播放、拖动和恢复使用同一数值轨迹。曲线表示模型计算结果。

## 图形与参考系

空间图从轨道北侧观察，公转方向为逆时针，图的坐标系随地月连线转动。月球上的圆点和两个不等形斑块固定在物质表面，转角为自转转角减去轨道转角；潮汐形变的长轴则由当前转速差决定。自转趋近公转时，物质标记相对地球方向的移动趋缓。

天体尺寸与形变放大显示。滞后角以有界单调映射放大：月球模式 δ画 = 0.42 tanh[(u−n/n₀)/1]，地球模式分母为 8，单位为弧度。该映射保持超前、落后与零滞后的关系；数值力矩由上面的耗散方程计算。图中的箭头分别标记自转力矩与轨道力矩方向，箭头长度使用图形尺度。地月演化模式的月球位置随 x 改变，虚线标出初始距离 a₀。

图中的“快速自转”“慢速自转”是可调初始条件；“当前转速比”采用圆整的 27.3。月球锁定模式中，另一颗天体的自转未进入角动量收支；地月演化模式同理。原日地月工具继续承担真实平均周期、月相、天平动及食的几何展示。
