# 宇宙膨胀：模型与来源

本工具的点阵、波形和曲线由下列方程生成。星系字母表示共动模型中的观察者；图表中的点取自同一模型。界面不使用观测目录或超新星样本。

## 空间与光波

采用空间平直、均匀各向同性的 FLRW 几何。今天尺度因子为 a = 1，共动星系的二维格点间距为 60 Mpc。选定观察者后，星系间同刻物理距离为 d = aχ，相对退行速度为 v = H(a)d。字母 A、B、C 可切换原点；每个星系标记的绘制大小固定。速度箭头按同一比例绘制。

模型仅包含非相对论性物质和宇宙常数，ΩΛ = 1 − Ωm，H(a) = H₀√(Ωm/a³ + ΩΛ)。默认 H₀ = 70 km s⁻¹ Mpc⁻¹、Ωm = 0.3、ΩΛ = 0.7，参数在距离模式中可以调整，并共享至空间模式。

波形固定发射尺度因子 a_emit = 0.5、发射波长 400 nm。当前接收波长为 λ_obs = λ_emit a/a_emit，红移 z = a/a_emit − 1；两行波形使用同一水平波长尺度，振幅为示意。尺度滑块直接选取宇宙尺度，未赋予匀速拖动任何宇宙时间间隔。空间点阵呈现同一时刻的几何，波形比较发射与接收的波长。

## 光度距离与膨胀历史

设 E(z) = √[Ωm(1+z)³ + ΩΛ]，计算

$$
D_C(z)=\frac{c}{H_0}\int_0^z\frac{dz'}{E(z')},\qquad
d_L(z)=(1+z)D_C(z),\qquad
\mu=5\log_{10}(d_L/\mathrm{Mpc})+25.
$$

c = 299792.458 km/s，积分采用 1024 个等分区间的复合 Simpson 法。界面取 0 ≤ z ≤ 1.2、50 ≤ H₀ ≤ 90 km s⁻¹ Mpc⁻¹、0 ≤ Ωm ≤ 1，忽略辐射密度。所有密度参数指今天的成分密度与临界密度之比。

实线对应当前 Ωm，虚线为相同 H₀ 的 Ωm = 1、ΩΛ = 0 模型。下图 Δμ 为实线距离模数减去虚线距离模数。两种模型中相同总光度光源的通量比为 (dL_matter/dL_current)²；光度与通量均对全部波长积分。固定滤镜观测的波段转换另需 K 校正。

默认模型在 z = 0.5 的光度距离为约 2832.938 Mpc，纯物质模型约 2357.697 Mpc，Δμ 约 0.39874 mag。模型参数为教学比较取值。图上的曲线比较也可与已有 Ia 光变标准化工具共同使用。
