## 官方 MIST 模型数据：已获取，已读格式

- [MIST 官方演化轨道插值器](https://mist.science/interp_tracks.html)：实际读表单，POST 到 `https://mist.science/track_form.php`，参数 `version=MIST2, v_div_vcrit=vvcrit0.0, mass_type=list, mass_list=1 3 15, new_met_value=0, alpha_value=p0, output_option=theory`。响应实际返回 [本次三个质量的 ZIP](https://mist.science/output/MIST_eep_6ac070f22b8fb.zip)；该临时服务器链接可能过期，原文件与哈希已保留本地。
- [官方模型库](https://mist.science/model_grids.html)：实际读取版本、EEP 与旋转/成分目录；v1.2 全质量包约96 MB，本轮没有下载该包，而使用三个质量的 v2.5 插值响应。
- [官方列定义及 EEP 表](https://mist.science/README_tables.pdf)：实际读取 Table I 与 Table II。年龄是年，质量是太阳质量，log_L、log_R 是太阳单位的常用对数，log_Teff / log_center_T 是 K 的常用对数；central abundance 是质量分数。he_core_mass 与 c_core_mass 是不同组成边界定义的核心质量，不能相加成总核心。旧表中低质量的 WD 入口1710与本次头部1420不同，因此新文件头部优先。
- [EEP 数据格式说明](https://mist.science/README_overview.pdf)：实际读取说明，EEP 是从原始 history 重采样的演化坐标，不等于等时间间隔。这个 PDF 介绍的是旧版本，不能将 v7503 写到实际 v2.5 文件上。
- [MIST II 论文正文](https://arxiv.org/html/2602.22012v1)：实际读取 §II.6、II.7、II.8 及新增量描述。MIST II 模型采用 MESA 11701，单星轨道范围受质量限制；该版正文写低/中质量止于后AGB并另有更新白矮星冷却研究。本次在线响应却含更晚的冷却段和未定义 phase=-9 的终点。为避免拿未核清的扩展冒充论文覆盖，本演示保留 1、3 M☉ 到头部第1420 EEP，15 M☉ 到第808 EEP（碳燃烧末），没有绘制白矮星冷却或后续超新星定量轨迹。

实际文件头部均为 **MIST 2.5 / MESA 11701**，初始 `[Fe/H]=0, [a/Fe]=0, v/vcrit=0, Y=0.2703, Z=0.0163577`。这与论文的太阳标定专用模型 Y/Z 数值并不相同，不借太阳标定的成分覆盖文件自身成分。初始质量1、3、15 M☉，当前质量随模型失质量变化。

本地 `data/stars/tracks.json` 保留全部1420、1420、808行，未构造年龄或补出缺失演化。`prepare.py` 从原始168列中定向提取17列；原始ZIP、3个EEP与每份SHA256可核对，JSON记录请求与哈希。浮点数不为展示而改写，只在界面显示时舍入。大质量文件沿用的 phase 数码不能在后期无条件解释成低质量TPAGB，模块以质量+EEP阶段范围描述。

## 机制与几何：已实际读取的主源

- [NASA 恒星类型](https://science.nasa.gov/universe/stars/types/)：读取主序、巨星、白矮星、中子星段。用于区分核心/包层与恒星遗迹。网页某些概括把聚变说成直接的力；模块采用原文章更精确的“聚变提供能量、压力梯度承担支撑”，也不采用统一初始质量阈值自动规定遗迹。
- [NASA SVS Pulsar Blinking](https://svs.gsfc.nasa.gov/10582)：实际读取灯塔、自转轴/磁轴不对齐、视线扫过的描述。只作为机制核验，没有下载第三方制作动画，也未声称与它逐帧比对。
- [NASA/Chandra：几何解释不同波段脉冲可见性](https://www.nasa.gov/image-article/chandra-images-show-that-geometry-solves-pulsar-puzzle/)：实际读取 Geminga/B0355+54 解释。射电、γ发射范围不统一，因此本实验仅把有限实心锥当射电灯塔示意，不能称全波段普适预测。
- [NASA/Caltech：Sloshing Star Goes Supernova](https://science.nasa.gov/photojournal/sloshing-star-goes-supernova/)：实际读取冲击停滞、中微子加热、多维流动的说明；该素材 Copyright Christian Ott/Caltech，本轮没有下载或复制视频。
- [Janka 2012：Explosion Mechanisms of Core-Collapse Supernovae](https://arxiv.org/abs/1206.2503)：实际读论文摘要及出版记录，约束中微子加热/非径向流动参与、不同能量事件不统一。本轮未阅读全文，不能把阅读摘要登记为全文核验。
- [NASA 黑洞结构](https://science.nasa.gov/universe/black-holes/anatomy/)：实际读视界、阴影、光子轨道、吸积盘与透镜段；本模块没有伪造黑洞成像。

有尝试但未用来支撑新核验的页面：NASA 独立 neutron-stars URL 无法取得；MPA archive返回错误；PMC文章停在reCAPTCHA。2009年的NASA超新星旧讲义已读，但简单“反弹自动炸开”与固定质量阈值表述不作为实现依据。无关Uranus URL误查询404，未使用。

## 计算与显示的明确区别

**恒星**：每点有效温度、光度、半径、中央温度/成分与核心质量来自模型。半径用 `0.6+0.58 log10(1+R/R☉)` 压缩，太阳参考同函数；核心显示半径分数按阶段选择0.38/0.14/0.18/0.66，**这不是MESA内部径向剖面**。燃烧壳的位置、厚度与表面颜色均示意。L=4πR²σT_eff⁴ 作为数据一致性检查，不用它另造演化点。EEP等步播放强调阶段关系，实际年龄独立显示，不造匀速寿命。

**脉冲**：磁轴 `[sinα cos2πφ, cosα, sinα sin2πφ]`；观察方向 `[sinζ, cosζ,0]`。最近一束夹角 `acos(abs(b·n))`，夹角≥半角则信号严格为零；束内强度为人工选择 `cos²(πθ/2ρ)`。占空比是720个相位样本的几何比例。慢放每四秒一周，物理周期只缩放横轴；不存在背景伪脉冲、模拟噪声或伪造实测信号。球体和束长非同比例。

**坍缩**：过程参数0—1控制核心向内缩、成功分支外壳向外移，未成功分支外壳不飞出。核心0.7→0.07、包层2→4.7均为显示单位；无秒或真实km标度，不求解流体/输运。中子星引力能量尺度 `GM²/R` 采用 1.4 M☉、12 km，只作牛顿量级估算，不称相对论束缚能或可见光总能。

**潮汐**：G=6.67430×10⁻¹¹ SI、c=299792458 m/s、M☉=1.98847×10³⁰ kg、R☉=6.957×10⁸ m、T☉=5772 K采用常用名义/近似常量。非旋转视界2GM/c²；长度2m的差异尺度2GMℓ/r³。视界附近只比较径向潮汐本征尺度，不据此宣称完整强场轨迹或材料破坏预测；未计算洛希极限、吸积与光线透镜。

## 2026-10-04：赫罗图先导与剖面修订

本节对应当前 `stars.js`、`stars-hr.mjs`、`stars-hr-renderer.js` 与 `stars-structure.js`。上文的半径压缩函数和旧核心显示分数是旧版三维剖面的记录；当前演化页改为固定图面大小的组成切面，不用圆大小表示实际恒星半径，实际半径仍读取同一 MIST 表，原数据未重算。

本轮实际打开读取：

- [OpenStax Astronomy 2e §18.4 The H–R Diagram](https://openstax.org/books/astronomy-2e/pages/18-4-the-h-r-diagram)：Features、Understanding the Main Sequence 与 Figure 18.14/18.15 的文字说明。用于温度向左增加、光度向上增加，主序、巨星、超巨星、白矮星的相对区域，以及同温度时半径影响光度的解释。未复制教材图像，也未把该教材的个别样本表或星数比例移入本页。
- [OpenStax Astronomy 2e §22.1](https://openstax.org/books/astronomy-2e/pages/22-1-evolution-from-the-main-sequence-to-red-giants)：主序核心氢聚变、氢耗尽后核心与外部的变化、质量对寿命的影响。剖面只显示组成边界和供能位置；氦聚变及后期阶段沿用当前课程正文与已有 MIST 阶段记录。
- [IAU 2015 Resolution B3，工作组全文](https://arxiv.org/html/1510.07674v1)：太阳名义有效温度5772 K、半径6.957×10⁸ m、光度3.828×10²⁶ W以及“名义换算值不等于最新实测估计”的说明。页面以太阳名义位置作参照，不声称进行了新的太阳观测。

新赫罗图的轴为有效温度K与光度L☉，两轴均为对数刻度。区域轮廓为原创教学示意，不是观测样本、精确分类边界或星数密度；也没有用主序带充当每颗恒星必经的演化路线。除太阳名义位置外，12000 K/100 L☉、3200 K/0.015 L☉、4500 K/100 L☉、3600 K/10⁵ L☉、16000 K/0.01 L☉均为手选类别示例，未命名为真实恒星。两组关系比较点是5772 K/1与100 L☉，以及1 L☉/5772与11544 K，均为构造示例，不保证稳定恒星恰好具有这些参数。

辐射半径由 `sqrt(L/L☉)*(5772/T_eff)^2` 推得。独立测试使用SI形式 `sqrt(L/(4πσT_eff⁴))` 与太阳名义单位，允许名义温度取整带来的小偏差；另验同温度100倍光度→10倍半径，同光度2倍温度→1/4半径。演化图横轴扩到20万K，完整容纳原1/3 M☉后AGB高温入口，仍未接入白矮星冷却轨道。

当前剖面左侧表示包层表面，右侧为组成切面。核心显示分数、壳层位置、厚度、颜色、能量箭头均为教学示意；不是密度、温度、对流区或MESA径向profile。箭头只说明能量向外传递，没有求解辐射输运或对流。晚期大质量星不绘制未取得的洋葱壳细节。主序、氢壳层、核心氦聚变、渐近巨星双壳层、后AGB分别显示阶段限定。
