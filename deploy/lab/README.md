# AstronomyLab R1 本地运行包

需要已有 Node.js >=22，无 npm 依赖。解压后在本目录运行 `node web/observatory/server.mjs --port 4182`，打开 http://127.0.0.1:4182/ 。首次运行不需要外网，不通过 file:// 双击。三维工具需要 WebGL2；图像与星光采用二维绘制。

不包含 course、文章 HTML、课程目录或段落映射。可选外置阅读包：追加 `--lectures "<lectures-web绝对目录>"`；无外置包的旧阅读路径显示开发期资料说明。兼容说明不代表正式部署迁移已完成。

这是本地工程候选版；MIST/M17 衍生数据再分发待核，不能直接公开分发。原图署名与模型来源随资源保留。没有账号、云端存档或视频频道。场景配方是输入配方，图像临时对照不随配方保存。

部署需另行授权；仅支持站点根路径。实体手机、现场投影、真人科学审校与试讲待进行。
