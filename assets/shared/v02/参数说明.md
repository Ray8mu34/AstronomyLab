# 行星参数的口径

`planet_parameters.csv`保留八颗行星的体积等效平均半径、质量与整体平均密度。数据来自[JPL Solar System Dynamics — Planetary Physical Parameters](https://ssd.jpl.nasa.gov/planets/phys_par.html)，不是从本包旧版图形反向读出的值。列名直接包含单位：半径为千米，质量为10²⁴千克，密度为克每立方厘米。CSV采用UTF-8 BOM，便于常见表格软件识别中文。

体积等效平均半径，是与该天体具有相同体积的球体半径。使用它时，体积比可以写成`(R / R_Earth)^3`；不要改用赤道半径却仍声称得到了准确体积比。采用表中数据，木星体积约为地球的1321倍，质量约为318倍。正文中的约数用于解释量级，并非要求读者记住所有有效位。

数据表的半径、质量与密度来自同一来源，但分别有测量误差和四舍五入；用表面保留的数字重新相除，不必在所有末位完全相等。巨行星的半径还依赖约定的参考层面，不能理解为走到一块坚硬地表后量出的半径。模型与误差的进一步说明以JPL原表脚注为准。

本表不含卫星总数、当前可见性、未来观测日期，也没有把不同来源的恒星周期与回归周期混成一个“公转周期”列。它是支持正文比较和后续作图的数据，不是一份记忆清单。
